Projeto 1 — Tabuada em C

Este projeto foi desenvolvido em linguagem C no Dev-C++. O programa solicita dez números ao usuário e mostra o resultado da multiplicação de cada número por 2.

Tecnologia: Linguagem C

O que pratiquei: Variáveis, laço de repetição, entrada de dados e operações matemáticas.

Ver código do projeto 
#include <stdio.h>

int main() {
    int a;
    int b;
    b = 2;
    int result;
    int i;

    for (i = 0; i < 10; i++) {
        printf("digite o valor de a\n");
        scanf("%i", &a);

        result = a * b;
        printf("o resultado de %i x %i = %i\n", a, b, result);
    }

    return 0;
}

Verificador de aprovação em C

Esse projeto foi desenvolvido em linguagem C utilizando o Dev-C++. O programa solicita a nota do aluno e verifica se ele foi aprovado ou reprovado, considerando a média 7,0 como critério de aprovação.

Tecnologia: Linguagem C

Ver código do projeto 
#include <stdio.h>

int main() {
    float m;

    printf("Insira a nota:\n");
    scanf("%f", &m);

    if (m >= 7.0) {
        printf("Aluno aprovado(a)!\n");
    }
    else if (m < 7.0) {
        printf("Aluno reprovado!\n");
    }

    return 0;
}
